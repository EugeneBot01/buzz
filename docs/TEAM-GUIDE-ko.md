# Buzz 팀 사용 가이드 (파라파라)

깃헙·AI를 몰라도 되는 사용법만 모았습니다. 막히면 **Buzz를 껐다 켜고**, 그래도 안 되면 구윤에게 연락하세요.

> 🖼 표시는 화면 캡처가 들어갈 자리입니다(시험판에서 찍어 채울 예정).

---

## 1. 설치 (맥, 처음 한 번만)

1. 맥에서 **터미널** 앱을 엽니다(Spotlight에서 "터미널" 검색).
2. 아래 한 줄을 붙여 넣고 엔터:
   ```
   curl -fsSL https://raw.githubusercontent.com/EugeneBot01/buzz/team/install.sh | bash
   ```
3. Buzz가 열리면 원래 쓰던 계정으로 로그인됩니다(계정·채널·메시지는 앱이 아니라 서버에 있어서 그대로 남아요).
4. "키체인" 창이 뜨면 맥 비밀번호 입력 → **항상 허용**.

- Apple 칩 맥·Intel 맥 모두 됩니다.
- **윈도우는 아직 설치할 수 없습니다.** (유진·민찬: 준비 중)

## 2. 업데이트

- 새 버전이 나오면 **사이드바 왼쪽 아래에 "업데이트 준비 완료" 배너**가 뜹니다. 🖼
- **누르기만 하면** 앱이 다시 켜지면서 업데이트됩니다. 다시 설치할 필요 없어요.

## 3. 채널

- **섹션**: 사이드바 채널 묶음은 팀 전체가 같이 쓰는 구성입니다. 누가 바꾸면 모두에게 똑같이 보여요.
- **전체 부르기**: `@everyone` = 사람만 전원, `@all` = 사람 + 에이전트 전원. `@`를 치고 Tab으로 자동 완성.
- **파일 모아 저장**: 채널 위쪽 파일 버튼 → 그 채널에 올라온 파일 목록 → 여러 개 골라 한 폴더에 저장. 🖼
- **바로가기(연결)**: 채널 위쪽 플러그 버튼 → 구글 미트 방·피그마 주소를 넣어 두면 채널 위에 버튼이 생깁니다. 🖼
- **음원(m4a·mp3·wav)**: 서버가 음원 파일을 그대로 받지 않아서 `노래.m4a.zip`으로 자동 포장돼 올라갑니다. 받는 사람은 메시지의 **[재생]**으로 바로 듣고 **[원본 저장]**으로 원래 파일을 받으면 됩니다. 🖼

## 4. 캘린더

사이드바 위쪽 **캘린더**.

- **일정 추가**: 날짜를 누르고 "일정 추가". 여러 날 일정, 시간, 색, 참석자, 반복(매일·매주·격주·매월)을 넣을 수 있어요. 🖼
- **채팅에서 바로 추가**: 메시지 위 `⋯` → **캘린더에 추가** → 날짜·시간이 채워진 창이 열립니다.
- **복사·붙여넣기**: 일정의 복사 버튼 → 붙일 날짜 고르기 → 붙여넣기 → 저장.
- **알림**: 참석자에게 하루 전·30분 전·10분 전 알림(내 알림은 일정 아래 "내 알림"에서 바꾸기).
- **채널 알림**: 일정에 채널을 정해 두면 저장할 때 / 시작 전에 그 채널에 글이 올라갑니다.
- **모임 날짜 투표**: "모임 날짜 투표" 탭 → 후보 날짜·시간 → 팀원이 되는 때를 누르고 "확인" → 가장 많이 되는 때에서 바로 "일정으로 만들기".
- **주간 공지**: "주간 공지" 탭에서 채널·요일·시각을 정하면 매주 그 시각에 그 주 일정이 채널에 올라갑니다. "일정 있는 날 아침 공지"를 켜면 일정마다 정한 채널에 오늘 일정 + 참석자 멘션. 🖼
- ⚠️ 알림·공지는 서버가 아니라 **누군가의 Buzz가 켜져 있을 때** 나갑니다. 그 시각에 아무도 안 켜 두면 처음 켜는 사람 앱이 올립니다.
- 구글 캘린더 연동은 아직 없습니다(준비 중).

## 5. 허들(통화)

- 채널이나 DM 위쪽 헤드폰 버튼으로 시작, 카드의 **Join**으로 참여.
- **한국어 자막**: 하단 바의 자막 버튼을 켜고 옆 **한/EN**이 "한"인지 확인. 자막은 허들 채팅에 올라가고, 다른 사람 말은 앞에 이름이 붙습니다. **한 회의에 한 명만 켜면 됩니다.**
- **사람 부르기**: 하단 바 사람+ 버튼 → 이름 검색 → [부르기]. 상대 DM에 통화 카드와 알림이 갑니다. DM 통화에서 부르면 새 그룹 DM에서 통화가 이어져요.

## 6. 에이전트(AI)

에이전트는 **만든 사람의 맥에서** 그 사람 계정으로 돌아갑니다. 그 맥이 꺼져 있으면 답하지 않아요. 부를 때는 `@에이전트이름` 멘션.

구윤이 들어가 있는 채널 기준으로 확인한 목록(2026-10-13):

| 이름 | 하는 일(소개 문구) | 있는 채널 | 누가 돌리나 |
|---|---|---|---|
| 리서치 | 주제를 받으면 자료를 찾아 출처와 함께 정리 | 연출팀·미술팀·포스트팀 | 확인 필요 |
| Fizz | 프로젝트 채널의 관리자 | 연출팀·미술팀·포스트팀 (+Welcome) | 확인 필요 |
| Pollen | 디자인 | 연출팀·미술팀 (+Welcome) | 확인 필요 |
| CHARACTER MAKER | 캐릭터 시트·여러 캐릭터 조합 테스트 | 연출팀·미술팀 | 확인 필요 |
| 매니저 (3개) | 회의록 기록·체크리스트 / 스케줄 관리 | 연출팀(2)·프로듀서앤디렉터(1) | 확인 필요 |
| 회의록봇 · Claude / GPT | 개인 비공개 채널의 회의록 → 체크리스트·스프린트 표, #채널 배포 | 회의록-권구윤(시험) | 구윤 |
| 개발 | (소개 없음) | 제작부 | 확인 필요 |
| Honey | (소개 없음) | Welcome | 확인 필요 |

- 구윤이 안 들어가 있는 팀 채널(촬영·안무·음악 등)의 에이전트는 이 표에 없습니다.
- "누가 돌리나"는 각자 확인 후 채워 주세요(같은 이름의 에이전트가 여러 개인 경우가 있어요).

## 7. 문제가 생겼을 때

1. **Buzz를 완전히 껐다(⌘Q) 다시 켜기.**
2. 업데이트 배너가 있으면 누르기.
3. 키체인 창이 뜨면 맥 비밀번호 → 항상 허용.
4. 그래도 안 되면 **화면 캡처 + 무엇을 했는지 한 줄**을 구윤에게 보내 주세요.
