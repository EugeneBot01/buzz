# 94-settings-ui-clarity.patch — 주간 공지·구글 캘린더·바로가기 화면 쉽게

구윤 요청(10/13): "주간공지·연결창 뭐가 뭔지 하나도 모르겠다". 기능은 그대로, 화면 문구와 배치만 바꾼다.

- 기준: `10`~`93` 위(55·70·91이 만든 화면 파일을 고친다).

## 1. 범위
- **공통**: 맨 위 상태 줄(켜짐/꺼짐 + 지금 무엇이 되는지 한 문장), 번호 단계(`Step`, `StatusLine` — `DigestPanel.tsx`에서 export).
- **주간 공지(55)**: ① 어느 채널 ② 언제 ③ 켜기 순서. 채널을 안 고르면 ③에 "1번에서 채널을 먼저 골라 주세요". 오른쪽 "이렇게 올라가요" 미리보기 + "지금 한 번 올려 보기".
- **구글 캘린더(91)**: "누가 하나요?" 안내, ① 코드 복사 ② 구글에서 배포(4줄) ③ 주소·비밀문구 넣고 켜기.
- **바로가기(70)**: 창 이름 "연결" → "바로가기 버튼", ① 링크 ② 이름 ③ 추가 라벨, 추가 전 "채널 위에 ○○ 버튼이 생겨요" 미리 문구, 에이전트 도구(MCP)는 "고급"으로 접음. 머리 버튼 툴팁 "바로가기 버튼 (미트·피그마 링크)".

## 2. 의도
데이터·동작은 건드리지 않는다. 다시 만들 때 기준: 처음 보는 사람이 위에서 아래로 읽으며 한 단계씩 하면 끝나는 순서, 기술 용어 없음.
