# 37-huddle-invites.patch — 디스코드식 허들 초대

통화 중에 사람을 바로 불러오는 기능. 허들 바에 **사람+ 버튼**이 생긴다.

## 1. 동작
- 사람+ → 이름 검색 → **[부르기]**
  1. 그 사람을 허들 방(임시 채널)에 `member`로 추가 → 원래 채널 멤버가 아니어도 입장 가능
  2. **내가 만든 허들이면**: 상대 DM에 진짜 허들 카드(kind 48100)를 보낸다. 모든 Buzz 앱이 이 카드를 Join 버튼 + 통화 알림으로 보여 준다(패치 없는 앱 포함). 릴레이는 "만든 사람이 서명한 48100이 있는 채널"을 통한 입장만 허용하므로 만든 사람만 가능.
  3. **남이 만든 허들이면**: DM에 초대 메시지(`<!-- buzz:huddle-invite:v1 … -->` + "📞 ○○님이 #채널 통화에 초대했어요.")를 보낸다. 패치된 앱은 [참여하기] 버튼 카드로 보여 준다.
- **"#채널에도 추가"** 체크(기본 꺼짐): 원래 채널 멤버로도 추가(기존 멤버·역할은 건드리지 않음).
- DM 허들이면 채널 이름("DM") 대신 "통화"로 표시.

## 2. 검증
- 프런트 테스트(초대 메시지 형식 3개 추가) 통과, `tsc`·biome·`cargo check` 통과.
- 1차 실사용(상대 앱 미패치): 상대가 허들 방 멤버로 추가되는 것까지 확인. 상대 앱에 카드가 없어서 새 허들을 만들거나 "not a member"가 나는 문제를 보고 2번(진짜 허들 카드로 부르기)을 추가.
- **미확인**: 양쪽 모두 패치된 상태에서의 실제 초대·입장. 팀 빌드 배포 후 확인 필요.

## 3. 의도 (충돌 시 재구현 기준)
- 백엔드 명령 2개: `invite_to_huddle(pubkey, addToParent)`(허들 방 추가 + 선택적 채널 추가), `ring_huddle_in_dm(dmChannelId)`(만든 사람만, DM에 48100).
- 초대 카드는 기존 손 흔들기(wave)와 같은 방식으로 메시지 본문의 HTML 주석 마커를 읽어 그린다.
