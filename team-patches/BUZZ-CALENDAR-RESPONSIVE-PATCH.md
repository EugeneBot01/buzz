# 108-calendar-responsive.patch — 좁은 창에서 일정 화면 깨짐 고치기

103 팀 캘린더·팀원 일정·함께 되는 시간 화면이 좁은 창에서 겹치던 문제를 고친다.

- 기준: `desktop-v0.5.28` + `10`~`107` 패치.

## 1. 증상
- Buzz 창 폭 약 1120px(일정 본문 약 600px)에서 "종일 불가 2" 배지가 글자 단위로 세로 분리·겹침.
- 날짜 숫자·"+N"·일정 막대가 서로 덮임. 오른쪽 날짜 패널이 폭을 계속 차지.

## 2. 동작
- 판정 기준은 창 폭이 아니라 일정 본문 폭(ResizeObserver). 순수 계산은 `lib/calendarLayout.ts`.
- 본문 < 860px: 날짜 패널을 달력 아래로 내림(`ui/ScheduleColumns.tsx`).
- 날짜 칸 < 110px: "종일 불가 N"·"불가 N"을 "●N"으로 축약, 전체 문구는 툴팁. 모든 배지·막대는 한 줄 고정·말줄임.
- 칸 높이에 맞는 막대 수만 보이고 나머지는 "+N". 날짜 숫자와 "+N"은 별도 머리 줄.
- 스프린트 표는 가로 스크롤, 팀원 일정·함께 되는 시간은 좁은 폭에서 세로 배치.

## 3. 검증
- 본문 600/800/1200px 실제 레이아웃(Vite 빌드 + 브라우저 DOM 측정): 겹침·넘침 0.
- `pnpm -C desktop test` 7,209개 통과(실패 0), `tsc --noEmit` 통과.
- 첫 날짜 칸이 로딩 뒤에 생겨도 다시 측정(콜백 ref) — 넓은 칸에서 "종일 불가 N" 전체 표기.
- 팀원 목록의 + 버튼에 "팀원 추가" 글자 표시.
