# 36-korean-transcripts.patch — 허들 한국어 실시간 자막 + 화자 구분

허들 자막(Captions 버튼)은 공식 Buzz에서 영어 전용 모델(NVIDIA Parakeet 110M)만 써서 한국어가 기록되지 않았다. 이 패치는 한국어 모델을 추가하고, 허들 바에 **한 / EN** 전환 버튼을 둔다.

## 1. 동작
- 자막 언어 기본값: 맥 언어가 한국어면 한국어, 아니면 영어. 허들 바의 `한`/`EN` 버튼으로 바꾸면 기억된다(`buzz-huddle-transcript-language`).
- 한국어 모델: **SenseVoice Small int8 (2024-07-17)**, 163MB. 앱 시작 시(한국어 선택이면) 백그라운드로 받는다. 받는 동안은 기존처럼 자막 버튼 옆에 진행률이 보인다.
- 자막 중 언어를 바꾸면 그 자리에서 새 모델로 다시 시작한다.
- 자막은 기존과 같이 허들 채널에 메시지로 올라간다. **자막을 켠 한 사람이 자기 목소리와 다른 참가자 목소리를 모두 받아 적으므로** 한 회의에 한 명만 켜면 된다.
- **화자 구분(영어·한국어 공통)**: 공식 Buzz는 다른 참가자 음성을 하나로 섞어 받아 적고 전부 켠 사람 이름으로 올렸다. 이 패치는 참가자별로 따로 받아 적고, 다른 사람 말 앞에 **이름**을 붙인다(예: `**성태엄마**: 아 근데 잘 모르겠어 이게.`). 내 말은 그대로. 이름은 프로필(kind 0)에서 한 번 조회해 캐시.

## 2. 모델 선택 근거 (2026-10-03 실측, M1 Pro)
가상 회의 문장 9개(마플·PPM·QC·DI 등 현장 용어 포함), 정답 대비 글자 오류율(CER)·처리 속도(RTF, 낮을수록 빠름):

| 모델 | 깨끗한 음성 CER | 잡음 섞인 음성 CER | RTF | 크기 |
|---|---|---|---|---|
| **SenseVoice 2024-07-17 (채택)** | **10.4%** | **15.6%** | **0.025** | 163MB |
| Zipformer Korean (한국어 전용) | 24.2% | 25.6% | 0.014 | 314MB |
| Whisper turbo int8 | 18.5% | 18.0% | 0.76 | 537MB |
| Whisper small int8 | 20.4% | 28.9% | 0.31 | 609MB |
| SenseVoice 2025-09-09 | 99% (한국어 깨짐) | — | — | 158MB |

- 2025-09-09판은 자체 동봉 `ko.wav`도 엉뚱한 문자로 나와서 날짜를 고정했다.
- 언어는 `auto` 대신 `ko`로 고정: 자막은 1~3초 단위로 끊겨 들어와 자동 감지가 중국어·일본어로 튈 수 있다. 영어 단어·약어는 그대로 나온다.
- 한계: 테스트 음성이 맥 TTS(유나)라 실제 회의 녹음보다 쉽다. 실제 회의에서 정확도 확인 필요.

## 3. 띄어쓰기 후처리 (`korean_spacing.rs`)
SenseVoice는 한국어를 조각 단위로 띄어 쓴다("확정 을", "했 습니다"). 조사·어미 목록에 있는 조각을 앞말에 붙이고, 숫자 뒤 단위(일·월·시·분 등)를 붙인다. 정답과 일치하는 단어 비율 47% → 56%. 완벽한 띄어쓰기 모델은 아니며, 회의록봇 요약에는 영향이 없다.

## 5. 의도 (충돌 시 재구현 기준)
- 원격 음성은 참가자(pubkey)별 VAD 스트림으로 받아 적고, 자막 항목에 화자를 싣는다. 게시할 때만 이름을 붙인다.
- 영어 모델 경로는 그대로 두고, 언어별 모델 슬롯을 하나 더 둔다. `stt_*` 접근자는 현재 언어의 슬롯을 가리킨다(프런트는 기존 `modelStatus.stt` 그대로 사용).
- 인식기 설정은 모델 폴더로 결정(`is_sense_voice_dir`), 한국어일 때만 띄어쓰기 후처리.
- 언어 전환 명령: `set_huddle_stt_language("ko" | "en")`.

- 프런트: 허들 테스트 95개, `tsc`, biome 통과.
- `desktop-v0.5.26` + 10·20·30·35 위에 `git apply --3way` 적용 확인.
- **실제 허들 확인(2026-10-03, 2인 DM 허들)**: 한/EN 버튼, 한국어 자막 게시, 상대 발화에 이름 표시 확인. 예: `**성태엄마**: 아니야 근데 난 우리는 그때 툴리를 만들었잖아.` / `영상 제작 하 면서 필 요한 것들만 생성을 하 던지…`
- 한계: 띄어쓰기가 단어 중간에서 끊기는 경우가 남아 있음("하 면서", "필 요한"). 후속 개선 대상.
